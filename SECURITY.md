# Security Policy

## Supported Versions
We currently support the following versions of GEMINIbot with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | ✅ Yes              |
| < 1.0   | ❌ No (please upgrade) |

---

## Reporting a Vulnerability
If you discover a security vulnerability, please follow these steps:

1. **Do not** open a public GitHub issue.
2. Instead, email us at: [ajaychitran9567@gmail.com]
3. Include as many details as possible (steps to reproduce, screenshots, logs).

We will review the report, verify the vulnerability, and respond within **7 days**.

---

## Disclosure Policy
- We will confirm the issue and work on a fix.
- Once resolved, we will release a patch and update the documentation.
- We will acknowledge your contribution if you wish.
